## Descargar

Entra en `001`, `002` o `003`, abre el MP4 o el WAV y pulsa **Download**. Ambos MP4 incorporan el audio. El WAV independiente dura6minutos.

Los MP4 y WAV se conservan mediante Git LFS por su tamaño. Al clonar el repositorio: `git lfs install` y `git lfs pull`.
